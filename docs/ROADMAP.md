# Roadmap

## v0.2 — Yandex Music

Add a Yandex provider with its own explicit capabilities, source resolution and
secure account flow. Keep provider-specific responses inside that module.

## v0.3 — Local files and unified library

Add local-file indexing/playback, album metadata and a unified cross-provider
library. Store authorized filesystem access in the native layer.

## Later

- Track-source matching and automatic fallback between authorized sources.
- Official SoundCloud OAuth and account features when application credentials
  and a secure token service are provisioned.
- Passwordless Reson identity/Discord OAuth, optional settings/library sync.
- Opt-in minimal adoption metrics; no songs, searches, playlists or local
  filenames sent to the backend.
- Registered Reson Discord application and wider presence validation.
- Code signing, in-app update channel and broader Windows device testing.
- Additional streaming providers and richer discovery.

This file describes intended direction, not delivered functionality.
